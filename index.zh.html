01 / LEARNING ROUTE

通过一次次系统评估建立深度

预备知识：编程及操作系统常识；按所选方向补 HTTP、TCP/IP、身份及云基础。时间安排仅供参考。

01

用两个晚上建立全局视野

阅读基础与方法，解释扫描与渗透测试的区别，明确一项属性并草拟评估范围，完成证据和覆盖练习。

02

完成一次应用评估

用一到两周结合隔离靶场或 Academy 练习学习 Web / API，捕获成对请求、验证一项发现、修复并复测。加入自动化前先学会代理。

03

选择一个深入方向

用两到四周深入网络、身份 / AD、云、主机 / 二进制、移动端或 IoT / OT。各方向独立，按接触的系统选择。

04

加入 AI 与可复现报告

分别学习 AI 辅助测试与 AI 系统安全，用一到两周评估一项有界辅助任务和一项示例 Agent 边界，写出证据及复测计划。

02 / DIRECTIONS

选择测试面

每个方向都有独立入口，可采用共同方法，无需把所有方向拼成一条攻击链。

03 / FIRST PROJECT

最小但有价值的产出

第一次评估应足够小，以便解释每个请求和决策。

TEST

两个用户、两个对象、一项属性

在训练应用比较所有者与非所有者读取，明确身份及示例数据。

REPORT

一项发现、一项修复、一次复测

说明预期属性、实际效果和限制，核验修复行为及合法访问。
