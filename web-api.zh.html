Web / API / FIELD GUIDE

测试身份、数据
与应用状态

Web 与 API 弱点常出现于授权边界、解析边界和业务不变量。

建模请求，而不只看 URL建立主体 × 对象 × 动作矩阵追踪每类问题破坏的边界业务逻辑需要不变量与状态
01 / FIELD NOTES

建模请求，而不只看 URL

端点由方法、身份、对象、输入模式及状态转换共同定义。

结合应用、文档与流量建立路由清单，按实际情况纳入 REST、GraphQL、WebSocket 和异步任务。记录认证上下文、租户、对象所有者、输出字段及后端依赖。区分未文档化路由与暴露的敏感操作；发现本身不等于影响。

对应资料：OWASP API Security Top 10:2023 ↗ · Burp Suite 文档 ↗

02 / FIELD NOTES

建立主体 × 对象 × 动作矩阵

认证证明身份；授权决定该身份能否执行此动作。

测试问题方法 / 证据结果解释
对象级访问比较两个普通用户及两个租户示例改变标识符不能跨越归属或租户边界
功能级访问以普通用户身份请求管理动作隐藏界面控件不等于服务端授权
属性级访问比较读取与更新路径的允许字段批量赋值与过量输出可独立失败
Token 生命周期用测试身份检查过期、注销、轮换与受众边界一个服务接受 Token 不意味着另一服务也应接受

对应资料：OWASP API Security Top 10:2023 ↗ · OWASP ASVS 5.0.0 ↗

03 / FIELD NOTES

追踪每类问题破坏的边界

先理解机制，再学习测试输入。

类别根本问题应寻找的证据
SQL / command injection数据是否变成可执行语法？输入到 Sink 的路径及受控后端行为
XSS / template injection哪个渲染上下文解释输入？实际浏览器或模板执行上下文，不只是反射
SSRF调用者输入能否控制服务端目标？目标策略、重定向、地址解析及网络位置
CSRF / session handling谁能触发已认证的状态变更？浏览器凭据、Origin 处理及防 CSRF 行为
Deserialization / upload不可信对象是否获得危险语义？类型约束、存储与执行隔离及解析行为
Request smuggling / cache confusion中间节点是否对报文或缓存边界有不同理解？受控代理链中可重复的差异效果

对应资料：PortSwigger Web Security Academy ↗ · OWASP WSTG v4.2 ↗ · MITRE CWE ↗

04 / FIELD NOTES

业务逻辑需要不变量与状态

语法有效的请求仍可能是无效业务动作。

写出“一张券仅能兑换一次”“转账不能跳过审批”“退款不能超过实收”等不变量。用示例数据测试角色变化、重放、替代顺序和并发。统计持久后端结果，而不只数成功 HTTP 响应。竞争条件练习使用有界小并发和可重置本地靶场。

对应资料：PortSwigger Web Security Academy ↗ · OWASP ASVS 5.0.0 ↗
