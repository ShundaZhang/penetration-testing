01 / FIELD NOTES

评估闭环

发现改变下一条假设，证据改变下一项决策。

规划目标及边界，发现资产和行为，形成有可证伪预期的具体假设，再用受控对照验证。记录前提、证据和实际影响，解释根因、提出修复，再复测同一属性。另行记录阻塞或未测试路径。

对应资料：NIST SP 800-115：测试与评估 ↗

02 / FIELD NOTES

组合盲点不同的方法

没有单一扫描器、框架或访问级别能看到整个系统。

方法优势盲点 / 后续工作
设计 / 威胁模型评审缺失的边界与不安全假设需要验证部署行为
SAST / code review数据流与隐藏路径可达性、框架语义与运行配置
DAST / manual requests真实运行响应仅覆盖被测身份、状态和可达路径
配置 / 权限评审有效策略与过度信任策略组合与动态状态
模糊测试异常解析状态与崩溃Harness 质量与语义正确性

对应资料：OWASP ASVS 5.0.0 ↗ · Semgrep 文档 ↗ · GitHub CodeQL CLI ↗ · AFL++ 文档 ↗

03 / FIELD NOTES

用对照隔离原因

一次改变一个有意义的变量，并使用控制样本比较。

测试问题方法 / 证据结果解释
访问控制是否失效？在同一示例数据上比较所有者、非所有者、另一租户和匿名请求200 状态本身不充分；检查受保护字段和对象归属
是否存在状态机失败？比较正常顺序、重复请求及禁止转换区分应用不变量与传输重试
输入是否引发后端行为？在受控环境中用成对的无害输入并关联追踪单次时延差异也可能来自缓存、负载或限速

对应资料：OWASP WSTG v4.2 ↗ · PortSwigger Web Security Academy ↗
