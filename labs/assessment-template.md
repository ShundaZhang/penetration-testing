# Assessment notebook / 评估笔记

Use synthetic records first. Separate observation, inference and untested possibilities.
优先使用示例数据，区分观察、推断及未验证可能性。

## Objective and scope / 目标与范围

- Protected property / 受保护属性:
- Assets, owners, environment and build / 资产、负责人、环境和构建:
- Test identities and vantage / 测试身份与观察位置:
- Permitted operations, time and request budgets / 允许动作、时间和请求预算:
- Exclusions, stop conditions and recovery / 排除项、停止条件与恢复:
- Evidence handling, retention and cleanup / 证据处理、保留及清理:

## Hypothesis / 假设

- Expected behavior / 预期行为:
- Attacker capability and prerequisites / 攻击者能力与前提:
- Controlled comparison / 受控对照:
- Observation that would falsify the hypothesis / 可推翻假设的观察:

## Coverage ledger / 覆盖记录

| Route / 路由 | Identity / 身份 | Object / 对象 | State / 状态 | Test / 测试 | Outcome / 结果 | Evidence / 证据 |
|---|---|---|---|---|---|---|
| | | | | | examined / blocked / not run | |

## Finding / 发现

- Title and violated property / 标题及被违反属性:
- Preconditions and exact fixture ownership / 前提及准确示例归属:
- Paired requests or controlled operations / 成对请求或受控操作:
- Expected versus actual behavior / 预期与实际行为:
- Redacted evidence references / 去敏证据引用:
- Confirmed impact, inference and limits / 确认影响、推断及限制:
- Root cause and recommended change / 根因及建议修复:
- Severity vector and business context / 严重性向量及业务背景:
- Confidence / 置信度:

## AI assistance provenance / AI 辅助来源

- Model, tool and configuration versions / 模型、工具及配置版本:
- Approved processing environment and minimized data / 获准处理环境及最小化数据:
- Generated hypothesis or code / 生成假设或代码:
- Independent verification and human intervention / 独立核验及人工介入:
- Scope, capability and execution budget controls / 范围、能力及执行预算控制:

## Retest / 复测

- Original forbidden case / 原始禁止案例:
- Legitimate access / 合法访问:
- Alternate identities, routes and states sharing the cause / 共享根因的其他身份、路由和状态:
- Fixed / partial / not fixed / not retested / 已修复、部分修复、未修复、未复测:
- Cleanup verified and remaining limits / 已核验清理及剩余限制:
