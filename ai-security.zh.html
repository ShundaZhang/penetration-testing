01 / FIELD NOTES

生成探测前先画系统

模型、编排器、检索库、连接器和工具凭据有不同权限。

列出可信指令、不可信输入、检索文档、长期记忆、可用工具及受保护资源。纳入传统 Web / API 和 IAM 层：AI 服务可能同时有普通授权缺陷和 AI 特有失败。分别说明攻击者对直接提示、检索内容、训练数据和模型制品的知识与访问能力。

对应资料：NIST AI 100-2 E2025 ↗ · MITRE ATLAS ↗

02 / FIELD NOTES

注入在跨越安全边界时成为安全发现

出人意料的回答不等于未授权资源访问。

测试问题方法 / 证据结果解释
直接 / 间接提示注入在用户提示或示例检索文档放入受控指令记录应用是否泄漏受保护示例或执行禁止动作
检索隔离创建两个租户语料并比较检索文档身份相似度搜索不能替代访问过滤
记忆污染使用可重置会话，追踪哪些内容进入持久记忆区分当前上下文行为与跨会话持久影响
输出处理检查生成文本在哪变为 HTML、查询、代码或工具参数下游解释器应把模型输出视为不可信输入

对应资料：OWASP LLM Top 10:2026 ↗ · OWASP Agentic Top 10:2026 ↗

03 / FIELD NOTES

把委派工具作为困惑代理问题测试

模型不应使用用户或流程未授予的权限。

对 MCP 及其他连接器接口，检查工具 Schema、来源、认证、Scope、Audience 和逐用户资源检查。测试低权限用户能否诱导高权限连接器访问受保护示例。出站目标控制和逐动作授权应在工具服务中验证，而不只写进 System Prompt。连接器发现、工具调用和资源授权是不同阶段。

对应资料：OWASP Agentic Top 10:2026 ↗ · MCP 授权规范 ↗

04 / FIELD NOTES

模型层攻击需要明确威胁模型

对训练数据、推理输入及制品的能力对应不同实验。

方向问题解释
规避 / 对抗样本有界输入变化能否改变有意义的决策？衡量允许扰动、任务影响和基线
数据 / 模型投毒获准的数据或制品影响能否造成定向失败？记录攻击者控制及重新训练后的持久性
隐私 / 提取查询能否揭示受保护样例或近似受保护功能？使用示例 Canary，考虑偶然性与公开知识
供应链不可信制品或依赖能否执行或改变可信行为？追踪制品格式、加载器行为及签名 / 来源

对应资料：NIST AI 100-2 E2025 ↗ · MITRE ATLAS ↗

05 / FIELD NOTES

把评估器作为有限制的测量工具

除了模型响应，还要检查应用效果。

garak 提供 LLM 探测，PyRIT 提供可配置 AI 风险评估流程。固定模型、应用构建、检索语料、工具策略和评估器配置。对实际读写使用确定性检查，对模糊情况人工评审。随机性案例应按记录次数重复，并区分 Jailbreak、策略违规和已确认未授权动作。分类器命中不自动等于已验证利用。

注明风险资料版本

本章使用 OWASP LLM Top 10:2026、Agentic Top 10:2026 及 NIST AI 100-2 E2025。它们整理风险，但不提供完整应用测试计划，也不证明安全。
