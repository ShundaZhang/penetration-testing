练习 / FIELD GUIDE

练习推理过程
看清结果证明什么

四项使用示例数据的确定性浏览器练习，不向目标发请求、不执行工具、不调用模型服务；结果均为本地模拟。

授权证据覆盖Agent 权限
01 / AUTHORIZATION

检查授权矩阵

预期规则：普通用户仅读取自己的账单；Manager 可读取 / 更新自己租户中的账单。

就绪 — 选择案例

比较预期与观察决策，再更换实现。本地函数刻意模拟常见遗漏，不是服务端或可部署的访问控制库。没有受保护数据的 200 响应本身不能证明读取失败。

对应资料：OWASP ASVS 5.0.0 ↗ · OWASP API Security Top 10:2023 ↗

02 / EVIDENCE

让主张不超出证据

阅读给定示例观察，选择结论并对照推理。

就绪 — 选择案例

类别描述主张的依据，不描述严重性。严重的假设后果仍可能只基于未经验证的信号。

对应资料：NIST SP 800-115：测试与评估 ↗

03 / COVERAGE

统计实际检查了什么

计划矩阵：四种身份 × 两种动作 × 两种会话状态 = 16 项。

就绪 — 选择案例

记录为示例，区分已检查、阻塞和未运行。百分比仅衡量该矩阵覆盖，不代表无漏洞或整体安全。实际覆盖还需路由、输入、位置和业务状态。

对应资料：NIST SP 800-115：测试与评估 ↗ · OWASP WSTG v4.2 ↗

04 / AGENT AUTHORITY

保持原任务的能力边界

固定任务：租户 A 普通用户请求读取租户 A 文档；连接器持有范围较广的示例凭据。

就绪 — 选择案例

更改建议来源不会扩大任务允许动作。严格关口检查原有任务能力及用户 / 资源权限。本练习是确定性权限模拟，不是真实提示注入或 LLM 基准。

对应资料：OWASP Agentic Top 10:2026 ↗ · MCP 授权规范 ↗
